### Quick Guide

* **Features/Fixes:** Nicht direkt in `main` committen $\rightarrow$ eigenen Branch aufmachen (`feature/...` oder `fix/...`).
* **PRs:** Pull Request erstellen und kurz drüber schauen lassen.
* **Issues:** Bugs & Task-Tracking direkt im jeweiligen Repo über Issues.
